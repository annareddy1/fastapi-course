## Course Overview

This course walks through the fundamentals of building modern APIs with **FastAPI** using Python.

Topics covered include:

- Python refresher
- FastAPI basics
- CRUD operations
- Path and query parameters
- Request and response handling
- Pydantic data validation
- Status codes and error handling
- SQL databases and ORM
- Authentication and JWT
- Alembic migrations
- Unit and integration testing
- Routing and project structure
- Jinja templating
- Git and GitHub basics
- Deployment concepts

---

## What is FastAPI?

**FastAPI** is a modern Python web framework for building APIs.

It is known for:

- High performance
- Fast development speed
- Easy-to-read syntax
- Built-in validation
- Strong standards support
- Fewer bugs through type hints and automatic validation

Official documentation: [FastAPI Docs](https://fastapi.tiangolo.com/)
